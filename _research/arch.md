Our processor-specialization research connects instruction design, memory organization, compiler support, and processor integration. [APS](https://ieeexplore.ieee.org/document/11240817) (ICCAD 2025) establishes an open-source hardware-software co-design framework for RISC-V instruction extensions, and [Aquas](https://dl.acm.org/doi/10.1145/3831252.3834028) (ICCAD 2026) develops holistic co-optimization through MLIR. [ISAMORE](https://dl.acm.org/doi/10.1145/3779212.3790162) (ASPLOS 2026) finds reusable instructions using e-graph anti-unification, while [ScaleISA](https://dl.acm.org/doi/10.1145/3845814.3850048) (ASPLOS 2027) extends instruction customization through multi-level e-graph anti-unification. These efforts link application-level opportunities with hardware implementation and software use; the current APS flow connects selected instructions to memory-aware accelerator generation, matched Rocket/RoCC integration, and functional and processor-level evaluation.
